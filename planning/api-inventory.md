# API inventory

Every public export of every package entry point, for the 1.0 API freeze ([01-api-freeze.md](./01-api-freeze.md)).

Regenerate after `pnpm build` with `pnpm api:inventory > planning/api-inventory.md`, then copy back the Decision column.
Fill **Decision** with one of: **keep**, **rename** (to what), **internal**, **remove**.

## Findings from the first run (0.6.6)

- 14 packages, 23 entry points with types (plus 3 static SQL files in drizzle), 336 exports in total.
- `Rbac` had 10 public members marked `@internal`: `events`, `gate`, `permissionExists`, `permissionMatches`,
  `remember`, `resolveGuard`, `resolvePermissions`, `resolveRoles`, `resolveTeam`, `visibleTeams`.
  No package outside core used them. **Done:** they are now `#private`, and `RoleRbac`, `SubjectRbac` and `sync.ts`
  reach them through a module-private accessor set in a static block of `Rbac` (changeset `hide-rbac-internals`).
- No export is marked `@deprecated` today.
- nuxt has 3 entry points (`.`, `/server`, `/rule`), not 4 as the plan first said.
